## 已检查的外设用途与版本差异

对两个 ZIP 中第 1 个寄存器版本的源码检查得到：

| 外设 | 用途 |
|---|---|
| ADC1 | 摆杆角度模拟量，控制代码调用通道 3 采样 |
| ADC2 | 电源电压采集、低压保护 |
| TIM1 | 控制周期中断，初始化参数 `(49, 7199)`，对应原工程 5 ms 周期 |
| TIM3 | 电机 PWM，初始化参数 `(7199, 0)`，原工程标注 10 kHz |
| TIM4 | 电机编码器接口，读取位置，速度可由位置变化计算 |

上表针对已检查的寄存器版本，不可无条件套用所有变体。尤其两个 HAL `.ioc` 仅列出 ADC1，没有 ADC2，说明版本存在差异；后续应核对 HAL 实际调用链及采样通道，再确定需要保持或更新哪些配置。

资料更新记录写明：2023-05-30 将原先单 ADC 采集改为 ADC1、ADC2 采集不同通道。此记录也不能替代逐版本源码核实。

## 三线传感器与六线电机的解释

此前向用户解释的是常见接线结构，尚未逐针核对本设备连接器，不应把下表用作实际插针顺序或线色定义。

角度传感器三线通常为：VCC、GND、模拟 OUT。只有 OUT 接 ADC 输入，另外两根供电。

带编码器直流电机六线通常为：

| 线路 | 用途 |
|---|---|
| M+、M− | 电机两端，接电机驱动器 |
| VCC、GND | 编码器供电 |
| A、B | 编码器脉冲，接定时器编码器接口 |

控制链：STM32 PWM → 电机驱动器 → 电机。
反馈链：编码器 A/B → TIM4 → 位置与速度反馈。
实际供电电压、连接器顺序、引脚和线色仍需核对底板原理图与传感器手册。
