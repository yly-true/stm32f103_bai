# STM32 独立起摆和稳摆 · 第 49 轮

这份实验固件针对已校零的 WHEELTEC IP570 / STM32F103C8T6。小车从轨道中部、摆杆自然下垂启动，STM32 完成起摆、动态接手和稳摆。程序链接至 SRAM 的 `0x20001000`。复位后板卡回到原有 Flash 固件。

## 控制代码

- `swingup-20261106/hybrid.c` 每 5 ms 采样并驱动状态机，同时记录 ADC、编码器、原始 PWM 请求和实际输出。
- `swingup-20261106/swing_logic.h` 处理下垂过零换向、能量估计、接手资格、制动与行程保护。第 49 轮在 24° 窗口内检查来向与速度。进入竖直内窗两秒后，平稳状态采用两拍平均，把绝对值小于 600 的净请求留给下一组。
- `swingup-20261106/state_capture.h` 根据车位、车速、杆角和杆角速度计算接手与稳摆的电机输出。
- `calibration/App/Control/Config.hpp` 是本台实物的标定副本。实验构建优先使用这份配置，板级驱动和 HAL 从仓库原目录编译。

## 从源码复现

在仓库根目录运行。需要 Python 3、支持 C++14 的本机 GNU C++ 编译器，以及 Arm GNU Toolchain 14.2.Rel1（含 newlib-nano）。把工具加入 PATH；本机 C++ 编译器也可通过环境变量 `CXX` 指定可执行文件的完整路径。

```powershell
py experiments/round49/build.py
```

构建会执行三个本机检查，核对 SRAM 向量、栈余量和最终映像的 SHA256。产物为 `build/round49/capture.bin`。实物回读为 10868 字节，SHA256 为 `11e8aa4cb44d42c3954aeb140b411e66b1e06383165dcbd6763e61d01fcec45e`。

## 在原实验台运行

本机加载工具使用 pyserial，以及为原实验台归档的 `flash-before.json`（包含芯片 UID 和 USB 桥标识，随设备保管）。加载前会核验 USB 桥、芯片和原校零 Flash 哈希，SRAM 写入后会完整回读。若使用另一台倒立摆，请先核对接线、电机方向、角度零点和行程标定。上面的离线构建不需要连接板卡。

1. 拔下外接 12 V，保留 USB，将小车放在轨道中部、杆自然下垂，松开 USER 和 X1。
2. 在仓库根目录执行以下命令，把示例路径替换为本机的板卡记录。默认端口为 COM8。

   ```powershell
   py -m pip install pyserial
   py experiments/round49/run_capture.py --proof 'D:\实验记录\flash-before.json' --port COM8
   ```

3. 等待 SRAM 回读完成。终端首帧应显示等待态（phase=0）、按键松开（keys=0）、车位接近零和 cycles=0。人在运动范围外接上 12 V，等蓝灯快闪，按住 USER 约半秒再松开。需要提前中止时按 X1。
4. 进入竖直内窗后最多运行 90 秒。停机后拔下外接 12 V。采集程序观察到锁止及 USB 电压后释放串口。每轮数据保存在 `build/round49/runs/` 下的独立时间戳目录，包含原始 UART、解码表和传输统计。下一次运行前在断电状态下把小车放回中部并重新载入。

## 已有实物结果

第 49 轮从启动到接手为 10.730 秒，进入内窗后保持 90.000 秒，全程无人接触车杆，定时停机。最后一分钟电机指令每秒换向 29.13 次，杆在校零点 ±2° 内的采样占比为 97.66%。本轮采集 20171 个控制样本和 31743 个有效串口包，CRC 错误为零。这些数字来自一次独立启动。
